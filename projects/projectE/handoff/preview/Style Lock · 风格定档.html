  • 能用 .t-X / .c-X 就用 — 不要在 HTML 写 style="font-size:NNpx"
  • 中文正文最小 = --fs-body 18px（再小看不清）

  • placeholder mono 贴字仅作"监督"标，禁用作正文

动效规范 5 token · 8 模式 · live demo

原则：游戏 UI 要 snappy，不要 candy 过度。短交互 160-200ms，中等 240-280ms，反馈类用 overshoot。 下面的 demo 都可以 hover/click 实际触发。

时长 · 昂函 token

时长 (duration)

  • --dur-instant 80ms · 微反馈
  • --dur-fast 160ms · button / tab / hover
  • --dur-base 240ms · 选中 / 角标弹出
  • --dur-modal 280ms · modal enter
  • --dur-slow 400ms · overlay / cinematic

昂函 (easing)

  • --ease-out · enter · 走路入场
  • --ease-in · exit · 退场
  • --ease-soft · material 标准
  • --ease-pop · overshoot·反馈突显

强约束

  • 禁用 transition: all·只动明确列出的属性 (transform/opacity/box-shadow)
