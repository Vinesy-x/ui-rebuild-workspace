## 已确认事实(全局规则)

- **viewport**:448×960 竖屏(视频 HEVC 原始尺寸)
- **顶部 HUD 4 货币**:钞票 / 月入(蛙类图标 + ±/月) / 心(❤ + ±/月) / 道具(紫水晶 / 黄星)+ 用户头像(等级 22)+ 设置 / 日期角标
- **底部 5 Tab**:中央"主菜单"街景(fps_0035 / fps_0117 对话状态)+ 4 个外围 Tab(经营 / 心情 / 财富 / 关系) ⚠️ 待 design 校准具体 label
- **modal 模式**:深色蒙层 + 底板模糊可见(参照 projectB 模式)
- **顶部 sub-tab**:某些屏带 horizontal sub-tabs(银行 / 股票;食物 / 住房 / 运输 / 衣服 等)

## 时序证据(相邻帧跳转,强证据)

```
fps_0001 → fps_0002    技能 list → 升级"力量"+2 动画

fps_0050 → fps_0061    业务 list → 切底栏财富 → 投资屏
fps_0072 → fps_0080    商店 - 运输 → 切 sub-tab 食物 → 商店 - 食物
fps_0094 → fps_0105    任务 list → 字符窗口(从顶部头像 / 底栏字符)
fps_0117 → fps_0123    主菜单变体(MOTEL)→ 心情 / 幸福 list
```

## ⚠️ 待 design 实做时校准

1. **底栏 5 Tab 精确 label**:目前推断是 "经营 / 心情 / 财富 / 主菜单 / 关系",但 design 看 PNG 可能识别为别的
2. **fps_0117 对话场景** 是 modal 还是主菜单变体(街景换 + 单 NPC + 灰底栏)?
3. **fps_0094 底部"目标 / 字符" 2 子 Tab** 跟底栏 5 Tab 是什么关系(可能是任务屏专用 sub-tab)
4. **字符窗口 fps_0105** 是从底栏 Tab 进还是顶部头像 click 进?
5. **加速 / 经理 / 工作详情 / 礼物选择 4 个 modal 是否都有共享 DialogShell 模板** — design 自决,projectB 模式建议是 1 个共享 DialogShell

## 跟 projectB / projectB-final-ninja 的关系

projectE 是独立游戏("大掌柜"宋朝换皮 + 现代视频布局),工程结构复用 projectB:
- Vite Vue 3 + TS + Pinia + Vue Router
- Pinia store 控制 modal 浮层(`useModalStore.openCardId` 等)
- `router.afterEach` 切屏自动 reset modal
- SC2 数据不复用,projectE 自有(待加策划表 / 数据 JSON)
