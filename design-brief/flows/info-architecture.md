## 已确认事实(全局规则)

- **viewport**:448×960 竖屏
- **顶部 HUD 4 货币**:钞票 / 月入 / ❤ / 紫水晶(+ 黄星 / 日期角标)+ 用户头像(等级 22)+ 设置 ⚙
- **底栏 6 Tab**(用户确认):**技能 / 遇见 / 工作 / 业务 / 投资 / 物品** ⭐
- **modal 模式**:深色蒙层 + 底板模糊可见(scrim `rgba(0,0,0,.55-.65)` + `backdrop-filter: blur(8px)`)
- **入口约定**:
  - **顶部头像 click → 字符窗口**(`fps_0105`)— 用户确认
  - **主屏右侧黄色按钮 click → 目标进度弹窗**(`fps_0094`)— 用户确认
  - **底栏物品 Tab → 商店**(4 sub-tab:食物 / 住房 / 运输 / 衣服)— 用户确认
- **顶部 sub-tab**:某些屏带 horizontal sub-tabs(投资:银行 / 股票;商店:食物 / 住房 / 运输 / 衣服;字符:交易 / 升级)
