## 通用约定

- **关闭 X(右上)**:关闭当前 modal,返回上一屏
- **返回箭头(左上 ←)**:返回上一屏
- **绿色 / 蓝色 CTA**(接受 / 升级 / 购买):扣货币 + 完成动作 + 反馈动画
- **modal 蒙层**:深色 `rgba(0,0,0,.55-.65)` + `backdrop-filter: blur(8px)` + 底板可见
- **底栏 6 Tab**:始终可见,点击切顶级 Tab。**对话/事件弹窗中 → 底栏灰化 disabled**(`fps_0117` 类)
- **底板字段**:每屏标 `底板:[屏名]`

## 给 design 的注意事项

1. **行为契约不变,只视觉换皮**(现代 → 宋朝古风)
2. **文字内容可古风化**:
   - "汽车修理工" → "马车工匠"
   - "投资 - 股票" → "票号 - 商号股本"
   - "MOTEL 旅馆" → "客栈"
   - "幸福" → "心境"
   - "John Doyle 21 年份" → "王掌柜 21 岁"
   - "STARBUX / STREAMLIX / MCDONNALD'S" → 宋朝商号名(茶肆 / 戏班 / 食肆)
   - "在外赛车" → "蹴鞠"或"跑马";"喝啤酒" → "饮酒";"看电影" → "听说书";"玩台球" → "玩骰子"
   - "毒品窝点 MOTEL" → "私贩 / 黑店 / 客栈"
3. **底栏 6 Tab label** = **技能 / 遇见 / 工作 / 业务 / 投资 / 物品**(用户已确认)
4. **modal 浮层**用 Pinia `useModalStore` + `<ModalShell>` 共享外壳:
   - store API:`open(name: string, props?: object)` / `close()` / `currentModal: { name, props } | null`
   - `<ModalShell>` 挂在根 layout,根据 `currentModal.name` 渲染对应 modal 组件
   - `router.afterEach` 切屏自动 `close()`(避免跨屏残留)
   - 全部 modal 用同一 scrim:`rgba(0,0,0,.65)` + `backdrop-filter: blur(8px)`
5. **7 个共享组件**(8 agent 识别后必须复用,不允许各屏单独实现):
   - `ProgressListDialog`(幸福 0123 + 健康 0126)
   - `OptionPickerModal`(礼物 0020 + 约会 0022)
   - `PurchaseConfirmModal`(住房 0075 + 食物 0082)
   - `AsyncWaitModal`(卖车 0067-0069)
   - `CinematicScene`(购买成功 0077)
   - `UpgradeOverlay`(亲疏度升级 0014)
   - `JobPromoSplash`(工作促销 0041)
6. **8 种货币 + USD**:钞票 / 紫晶/钻石 / 砖(月入)/ ❤ / 😊 / ⭐ 黄星 / 🪙 黄币 / 🎫 门票 / 🃏 芯片 / USD(IAP)— **真钱档不实现**
7. **角标系统**:红 ! / 红数字 / 黄 ⚠ 促销 / 绿 ✓ / ❓ / FAIL / 🔒 / ❗ — 跨屏一致
8. **CD 机制**:
   - 短 CD(秒级):送礼 / 幸福行为 00:02(灰胶囊倒计时按钮)
   - 异步任务(天级):卖车 / 银行存款 03:48 / 业务解锁 23:19
   - 游戏 tick:随机事件触发(0117)
9. **解锁机制**:级别 N + 收集 ★N(技能 ⭐25/40,物品 ★24,业务时间门 23:19,工作 DAG 上游 ✓)
10. **DAG 树状视觉**(工作 0036):用毛笔笔触 / 纸卷折痕画连线;✓ 改朱印「成」 / FAIL → 朱印「敗」 / ❓ → 「未啟」 / 促销 → 「特」字红印
11. **HUD 双行结构**:行 1 = 头像 + 钞票 + 月入 + 紫晶 + ⚙;行 2 = 钞票月度增长 + ❤ + 黄星 + 日历。**每个数值 click 都有行为**(canonical 大补)
