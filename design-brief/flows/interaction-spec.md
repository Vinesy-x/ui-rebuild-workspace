# projectE · 大掌柜 — 交互行为契约(canonical)

> **本文档是每屏可点元素 + 跳转 / 关闭 / Tab 切换的 canonical**(行为权威)。
> 屏映射看 `info-architecture.md`,可视化看 `topology.html`。
> ⚠️ 视觉权威仍是 PNG;本文档基于"现代版视频"推断的行为,宋朝换皮后**布局结构不变,交互行为不变,只视觉换皮**。

## 通用约定

- **关闭 X(右上)**:统一行为 = 关闭当前 modal,返回上一屏(参照 projectB 模式)
- **返回箭头(左上 ←)**:统一行为 = 返回上一屏
- **绿色 / 蓝色"接受 / 升级 / 购买" CTA**:扣货币 + 完成动作 + 反馈动画
- **modal 蒙层**:深色 `rgba(0,0,0,.55-.65)` + `backdrop-filter: blur(8px)` + 底板可见(参照 projectB)
- **底栏 5 Tab**:始终可见(对话进行中除外?见 fps_0117 灰底栏),点击切顶级 Tab
- **底板字段**:每屏标 `底板:[屏名]`(modal 必标)或 `底板:无 — 整屏替换`(hub / fullscreen)
