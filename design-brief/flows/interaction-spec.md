# projectE · 大掌柜 — 交互行为契约(canonical)

> **本文档是每屏可点元素 + 跳转 / 关闭 / Tab 切换的 canonical**(行为权威)。
> 屏映射看 `info-architecture.md`,可视化看 `topology.html`。
> ⚠️ 视觉权威是 PNG;**布局结构 + 行为** 来自现代版视频,**视觉换皮宋朝**。

## 通用约定

- **关闭 X(右上)**:关闭当前 modal,返回上一屏
- **返回箭头(左上 ←)**:返回上一屏
- **绿色 / 蓝色 CTA**(接受 / 升级 / 购买):扣货币 + 完成动作 + 反馈动画
- **modal 蒙层**:深色 `rgba(0,0,0,.55-.65)` + `backdrop-filter: blur(8px)` + 底板可见
- **底栏 6 Tab**:始终可见,点击切顶级 Tab。**对话/事件弹窗中 → 底栏灰化 disabled**(`fps_0117` 类)
- **底板字段**:每屏标 `底板:[屏名]`

## 给 design 的注意事项

1. **行为契约不变,只视觉换皮**(现代 → 宋朝古风)
2. **文字内容可古风化**:
   - "汽车修理工" → "马车工匠"
   - "投资 - 股票" → "票号 - 商号股本"
   - "MOTEL 旅馆" → "客栈"
   - "幸福" → "心境"
   - "John Doyle 21 年份" → "王掌柜 21 岁"
3. **底栏 6 Tab label** = **技能 / 遇见 / 工作 / 业务 / 投资 / 物品**(用户已确认)
4. **modal 浮层**用 useModalStore + DialogShell 共享外壳(参照 projectB final/src/stores/useModalStore.ts + components/CardDetailDialog.vue 模式)
